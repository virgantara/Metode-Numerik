# Bab 04 — Interpolasi dan Aproksimasi Data

Kode pendamping Bab 4 buku **Metode Numerik**.

## Isi folder

| File | Isi |
|---|---|
| `01_data_diskret.py` | Representasi dan validasi data diskret |
| `02_lagrange_interpolasi.py` | Interpolasi Lagrange |
| `03_newton_interpolasi.py` | Interpolasi Newton dengan beda terbagi |
| `04_beda_hingga.py` | Tabel beda hingga, Newton-Gregory maju dan mundur |
| `05_regresi_linear.py` | Regresi linear least squares |
| `06_regresi_polinomial.py` | Regresi polinomial least squares |
| `07_visualisasi_regresi.py` | Visualisasi regresi linear dan polinomial |
| `08_visualisasi_interpolasi.py` | Visualisasi interpolasi Lagrange |

## Instalasi

```bash
python -m pip install -r requirements.txt
```

## Menjalankan contoh

```bash
python 01_data_diskret.py
python 02_lagrange_interpolasi.py
python 03_newton_interpolasi.py
python 04_beda_hingga.py
python 05_regresi_linear.py
python 06_regresi_polinomial.py
python 07_visualisasi_regresi.py
python 08_visualisasi_interpolasi.py
```

Kode pada folder ini ditujukan untuk pembelajaran konsep. Implementasi pustaka
seperti NumPy/SciPy tetap dapat digunakan sebagai pembanding pada aplikasi nyata.
